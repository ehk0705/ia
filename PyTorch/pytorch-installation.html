Installer et utiliser PyTorch pas à pas

Cette page explique comment préparer Python, créer un environnement propre, installer PyTorch, vérifier que tout fonctionne et lancer un premier programme.

Elle convient à un débutant qui veut avancer proprement, sans confusion entre CPU, GPU, pip et environnement virtuel.

Python 3 pip CPU GPU Test rapide
Commencer Vérifier PyTorch

1. Vue d’ensemble

PyTorch propose une installation locale officielle avec sélection de l’OS, du gestionnaire de paquets et de la plateforme de calcul. La documentation recommande les binaires précompilés pour la majorité des utilisateurs. :contentReference[oaicite:1]{index=1}

Cas le plus simple

Installer PyTorch en mode CPU avec pip. C’est le meilleur point de départ pour apprendre et tester les premiers scripts.

Cas plus avancé

Installer PyTorch avec prise en charge GPU. Cela demande un matériel compatible et le bon choix de plateforme de calcul sur le site officiel. :contentReference[oaicite:2]{index=2}

Règle importante

Ne copie pas une commande trouvée au hasard. Choisis toujours la commande adaptée à ton système sur le site officiel de PyTorch. :contentReference[oaicite:3]{index=3}

Pour la plupart des débutants, commencer avec CPU + pip + environnement virtuel est la bonne méthode.

2. Prérequis

Avant d’installer PyTorch, il faut un environnement Python propre.

Ce qu’il faut installer

  • Python 3
  • pip
  • Un terminal ou invite de commande
  • Un éditeur comme VS Code, PyCharm ou un simple terminal

Version Python

La documentation officielle indique actuellement une prise en charge de Python 3.10 à 3.14 selon les plateformes et la version récente de la documentation est 2.10. :contentReference[oaicite:4]{index=4}

Vérifier Python et pip

python --version pip --version

Sur certains systèmes, il faut utiliser python3 et pip3. La documentation officielle le signale explicitement pour Linux. :contentReference[oaicite:5]{index=5}

3. Créer un environnement virtuel

C’est une bonne pratique. Cela évite les conflits entre projets.

1

Créer le dossier du projet

mkdir mon-projet-pytorch cd mon-projet-pytorch
2

Créer l’environnement virtuel

python -m venv venv
3

Activer l’environnement

Windows :

venv\Scripts\activate

Linux ou macOS :

source venv/bin/activate

4. Installer PyTorch

La méthode officielle consiste à aller sur le sélecteur d’installation de PyTorch, choisir l’OS, le paquet et la plateforme de calcul, puis copier la commande fournie. :contentReference[oaicite:6]{index=6}

Installation simple en mode CPU

Pour un débutant, le plus simple est d’installer la version CPU sans dépendre d’un GPU.

pip install torch torchvision torchaudio

Installation avec GPU

Avec une carte compatible, la commande dépend de la plateforme de calcul choisie. Il faut récupérer la commande exacte sur le site officiel. :contentReference[oaicite:7]{index=7}

# Exemple : ne pas copier sans vérifier # Utiliser la commande fournie par le site officiel PyTorch
Mauvaise idée : installer un paquet GPU au hasard. Bonne méthode : prendre la commande exacte générée par le site officiel.

5. Vérifier que PyTorch fonctionne

Après l’installation, il faut faire un test simple.

Test minimal

import torch print("Version de PyTorch :", torch.__version__) print("CUDA disponible :", torch.cuda.is_available()) x = torch.tensor([1.0, 2.0, 3.0]) print("Tenseur :", x)

Si tout va bien

Le programme affiche la version, puis un tenseur simple.

Si CUDA vaut False

Ce n’est pas une erreur si tu as installé la version CPU ou si ton GPU n’est pas configuré.

Si l’import échoue

Le plus souvent, l’environnement virtuel n’est pas activé ou l’installation n’a pas été faite dans le bon Python.

6. CPU ou GPU ?

Il faut comprendre la différence avant d’installer n’importe quoi.

Mode Avantage Inconvénient Pour qui
CPU Simple à installer Plus lent pour gros modèles Débutants, tests, petits projets
GPU Beaucoup plus rapide pour l’entraînement Configuration plus délicate Projets lourds, deep learning avancé

Test GPU

import torch if torch.cuda.is_available(): print("GPU détecté") print(torch.cuda.get_device_name(0)) else: print("GPU non disponible")

7. Premiers exemples

Une fois PyTorch installé, voici trois mini tests utiles.

Créer un tenseur

import torch x = torch.tensor([[1, 2], [3, 4]]) print(x)

Faire une addition

import torch a = torch.tensor([1, 2, 3]) b = torch.tensor([4, 5, 6]) print(a + b)

Tester un petit calcul différentiable

import torch x = torch.tensor(2.0, requires_grad=True) y = x**2 + 5*x + 1 y.backward() print("Gradient :", x.grad)

8. Structure simple d’un projet

Même pour un petit essai, garde un minimum d’ordre.

mon-projet-pytorch/ │ ├── venv/ ├── test.py ├── requirements.txt └── notes.txt

venv

Environnement virtuel du projet.

test.py

Script Python pour les essais PyTorch.

requirements.txt

Liste des paquets installés pour pouvoir recréer l’environnement.

9. Bonnes pratiques

Voici les réflexes utiles pour éviter les erreurs classiques.

À faire

  • Créer un environnement virtuel par projet.
  • Tester l’import de PyTorch juste après l’installation.
  • Commencer par CPU si tu débutes.
  • Utiliser le site officiel pour la commande exacte.
  • Noter la version de Python et de PyTorch.

À éviter

  • Mélanger plusieurs Python sur la même installation sans vérifier.
  • Installer un paquet GPU sans savoir s’il correspond au matériel.
  • Copier des commandes anciennes trouvées dans des forums.
  • Travailler hors environnement virtuel.
  • Confondre erreur d’installation et absence de GPU.
