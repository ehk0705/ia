Comprendre le protocole ARP

Le protocole ARP permet à une machine de retrouver l'adresse MAC correspondant à une adresse IP sur un réseau local. Sans lui, un appareil connaît peut-être l'adresse IP de destination, mais il ne sait pas à quelle carte réseau envoyer physiquement la trame Ethernet.

En pratique, ARP joue le rôle d'un annuaire local entre adresse logique et adresse matérielle. Il est simple, rapide, mais aussi vulnérable à certaines attaques si le réseau est mal protégé.

Voir le mécanisme Voir les risques
IP Adresse logique utilisée pour l'acheminement réseau.
MAC Adresse physique de l'interface sur le réseau local.
ARP Correspondance entre les deux, dans un même segment local.

1. Qu'est-ce que le protocole ARP ?

ARP signifie Address Resolution Protocol. Son rôle est de traduire une adresse IP en adresse MAC sur un réseau local de type IPv4. Une machine peut connaître l'adresse IP d'une autre machine, mais pour transmettre une trame Ethernet, elle doit connaître l'adresse MAC du destinataire local.

ARP intervient donc au point de rencontre entre la couche réseau et la couche liaison. Ce n'est pas un protocole de routage. Ce n'est pas non plus un mécanisme pour Internet entier. Il agit uniquement dans le cadre d'un segment local ou pour joindre la passerelle par défaut.

Idée clé

Pourquoi ARP est indispensable

Ethernet transporte des trames destinées à des adresses MAC. Or les applications et le protocole IP travaillent avec des adresses IP. ARP fait le lien entre ces deux mondes.

Sans ARP, une machine saurait où elle veut aller en termes logiques, mais pas à qui remettre la trame sur le réseau local.

2. Comment ARP fonctionne

Le fonctionnement d'ARP est simple. Lorsqu'une machine veut envoyer des données à une adresse IP locale, elle vérifie d'abord si elle possède déjà la correspondance IP-MAC dans son cache ARP. Si oui, elle utilise directement cette entrée. Sinon, elle lance une requête ARP.

Vérification du cache ARP

La machine source consulte sa table locale. Cette table contient des correspondances récemment apprises. Cela évite de refaire une diffusion à chaque envoi.

Requête ARP en diffusion

Si aucune entrée n'existe, la machine envoie une requête à tout le réseau local : Qui possède cette adresse IP ? Cette requête est envoyée en broadcast vers l'adresse MAC FF:FF:FF:FF:FF:FF.

Réponse ARP en unicast

La machine qui reconnaît son adresse IP répond directement à l'émetteur avec sa propre adresse MAC. La réponse est généralement envoyée en unicast.

Mise à jour du cache

L'émetteur mémorise la correspondance dans son cache ARP pendant un certain temps. Les communications suivantes seront alors plus rapides.

3. Les champs d'une trame ARP

Une trame ARP contient plusieurs champs permettant d'identifier le type de matériel utilisé, le protocole concerné, ainsi que les adresses source et destination. Pour une utilisation classique sur Ethernet et IPv4, voici les éléments les plus importants.

Champ Rôle Exemple
Type matériel Indique le support de liaison. Sur Ethernet, la valeur est généralement 1. Ethernet
Type protocole Indique le protocole réseau concerné par la résolution d'adresse. IPv4 : 0x0800
Taille adresse matérielle Longueur de l'adresse MAC en octets. 6
Taille adresse protocole Longueur de l'adresse IP utilisée par le protocole. 4
Opération Précise s'il s'agit d'une requête ou d'une réponse. 1 = requête, 2 = réponse
Adresse MAC source Adresse physique de l'émetteur. AA:AA:AA:AA:AA:10
Adresse IP source Adresse IP de l'émetteur. 192.168.1.10
Adresse MAC cible Inconnue dans une requête, renseignée dans une réponse. 00:00:00:00:00:00
Adresse IP cible Adresse IP recherchée. 192.168.1.20

4. Le cache ARP

Performance

Réduire les diffusions

Le cache ARP évite d'envoyer une nouvelle requête à chaque échange. Cela diminue le trafic inutile sur le réseau local.

Mémoire temporaire

Entrées limitées dans le temps

Les associations IP-MAC ne sont pas conservées indéfiniment. Elles expirent pour permettre l'adaptation aux changements du réseau.

Administration

Entrées dynamiques ou statiques

Certaines entrées peuvent être ajoutées manuellement, mais la plupart sont apprises automatiquement lors des échanges ARP.

Sous de nombreux systèmes, il est possible d'afficher la table ARP locale avec des commandes d'administration réseau. Cela permet de voir quelles adresses IP sont déjà associées à quelles adresses MAC.

5. Portée et limites du protocole ARP

  • ARP ne fonctionne que dans un réseau local IPv4.
  • Il ne traverse pas directement les routeurs.
  • Pour joindre un hôte situé sur un autre réseau, la machine résout généralement l'adresse MAC de la passerelle par défaut, pas celle de l'hôte distant.
  • ARP est lié au monde IPv4. En IPv6, il est remplacé par d'autres mécanismes, notamment le protocole de découverte de voisins.
À retenir

ARP n'est pas universel

Beaucoup de débutants pensent qu'ARP permet de retrouver directement n'importe quelle machine sur Internet. C'est faux. ARP sert surtout à déterminer le prochain saut local au niveau Ethernet.

Dès qu'il faut sortir du réseau local, la communication passe par la passerelle, et c'est l'adresse MAC de cette passerelle qui devient essentielle.

6. Sécurité : l'attaque par usurpation ARP

Le protocole ARP repose largement sur la confiance. Une machine peut accepter une correspondance IP-MAC reçue sans vérification forte. Cela ouvre la voie à l'ARP spoofing ou ARP poisoning.

Dans ce type d'attaque, un appareil malveillant envoie de fausses réponses ARP pour faire croire qu'il possède l'adresse IP d'une autre machine, souvent la passerelle. Le trafic peut alors être redirigé vers l'attaquant.

Conséquences

Ce que l'attaquant peut faire

  • intercepter le trafic ;
  • modifier certains échanges ;
  • bloquer la communication ;
  • se placer entre la victime et le routeur.
Mesure 1

Segmentation réseau

Réduire la taille des domaines de diffusion limite la portée d'une attaque ARP et facilite la surveillance.

Mesure 2

Contrôles de commutateur

Certains équipements gérés proposent des fonctions de protection comme l'inspection dynamique ARP ou des listes de confiance.

Mesure 3

Entrées statiques ciblées

Pour des équipements critiques, des associations fixes peuvent parfois limiter les risques, mais cela demande de l'administration et de la rigueur.

ARP n'est pas mauvais en soi. Il est simplement ancien, simple et peu défensif. Sur un réseau moderne, sa sécurité dépend surtout de la qualité de l'architecture et des équipements utilisés.

7. Différence entre IP, MAC et ARP

Élément Nature Rôle Exemple
Adresse IP Logique Identifier l'hôte au niveau réseau 192.168.1.20
Adresse MAC Matérielle Identifier l'interface sur le réseau local BB:BB:BB:BB:BB:20
ARP Protocole de résolution Associer IP et MAC en environnement IPv4 local Requête puis réponse

8. Exemple concret

Un ordinateur ayant l'adresse IP 192.168.1.10 veut envoyer un paquet à 192.168.1.20 sur le même réseau local.

Cas 1 : la destination est locale

L'ordinateur vérifie son cache ARP. S'il ne connaît pas encore l'adresse MAC de 192.168.1.20, il diffuse une requête. La machine cible répond avec son adresse MAC. La communication Ethernet peut alors commencer.

Cas 2 : la destination est distante

Si l'adresse IP visée est sur un autre réseau, l'ordinateur n'essaie pas de résoudre la MAC de la machine distante. Il résout la MAC de la passerelle par défaut, puis lui remet la trame.

9. Questions fréquentes

ARP fonctionne-t-il avec IPv6 ?

Non. En IPv6, le rôle de découverte locale est assuré par un autre mécanisme, notamment le protocole de découverte de voisins.

Pourquoi ARP utilise-t-il la diffusion ?

Parce que l'émetteur ne connaît pas encore le destinataire exact au niveau MAC. Il interroge donc tout le segment local pour trouver la bonne machine.

Pourquoi une réponse ARP n'est-elle pas diffusée ?

Parce que la machine qui répond connaît déjà l'adresse MAC de l'émetteur grâce à la requête reçue. Elle peut donc répondre directement.

Peut-on vivre sans ARP en IPv4 sur Ethernet ?

Pas de façon normale sur un réseau local classique. Il faudrait configurer manuellement les correspondances, ce qui est peu pratique et vite ingérable.
